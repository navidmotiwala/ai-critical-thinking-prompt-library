# Response quality prompts

### 1. Plain English

> Explain [topic] in simple English. Use concrete examples. Define necessary technical terms once. Avoid filler, exaggerated claims, emojis, em dashes, and generic AI phrases.

### 2. No fluff

> Answer [question] directly. Remove introductions that repeat the question, motivational language, unnecessary summaries, and repeated points. Keep every sentence useful.

### 3. Clear recommendations

> Recommend a course of action for [situation]. State the recommendation first, then the decisive reasons, risks, and next action. Distinguish judgment from fact.

### 4. Editorial cleanup

> Edit [text] for clarity, factual precision, and natural tone. Preserve meaning. Remove redundancy, vague qualifiers, unsupported superlatives, formulaic transitions, emojis, and em dashes. Do not add new claims.

### 5. Quality gate

> Before finalizing [answer], check whether it directly answers the question, uses supported claims, acknowledges important limitations, avoids duplication, and provides actionable detail. Return the revised answer only.
